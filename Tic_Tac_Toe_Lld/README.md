# Tic Tac Toe System

## Design Patterns Used

### Strategy Pattern
- TicTacToeRules

### Observer Pattern
- IObserver

### Factory Pattern
- TicTacToeGameFactory

### Composition
- TicTacToeGame contains Board
- Board contains Symbols

## Features

- Configurable Board Size
- Two Player Gameplay
- Turn-based Player Queue
- Move Validation
- Win Detection
- Draw Detection
- Observer Notifications
- Factory-based Game Creation
